# もしもラボ｜Design Handoff v2.0（レビュー用）

## 決定事項
- UI: Modern Fintech A。白・ネイビー・ブルー。過度な装飾を排し、視認性・可読性・理解可能性を優先する。
- イラスト: **承認済みC**。青空・水辺・新緑・自然光。家族（大人2＋子ども2）、シニア、単身男性、単身女性を基準とする。勝手にキャラクターを再生成したりテイストを変えたりしない。
- 保険会社・保険商品を売らない中立の診断。商品名・販売誘導・恐怖を煽る表現は禁止。
- 数値は計算エンジン由来のみ。AIやUIモックが金額を推定・創作しない。

## 開く
`index.html` をブラウザーで開いてください。`prototype/index.html` も同じ内容です。**幅390pxを基準**とした試作。ナビゲーション、シナリオ展開、条件入力の見た目を操作できます。

## この試作の範囲と注意
- 7画面：ホーム、条件入力、診断サマリー、もしもラボ、シナリオ詳細、履歴、ガイド。
- サンプル額は `design/variants/lab/README.md` に記載の計算済み数値を転記したもの。サンプル条件は `/lab?v=1&sb=1986&emp=self&sp=1&spb=1988&spe=none&ch=2018-2021&edu=private&inc=lt400&sinc=none&as=lt100&liv=lt35&ho=rent&cvs=none&cvsp=none`、算定基準日2026-10-17、計算パラメータ2026.08。画面内の選択はこの値に連動**しない**。
- グラフは「形状の表現例」であり、正確なエンジン時系列プロットではない。エンジンの25年分の数値に差し替えてから正式版とする。
- シナリオ詳細の内訳は創作していない。履歴は未接続の空状態。
- イラストは既存承認画像に由来する暫定切り抜き。シニア・単身男女の横長ヒーロー専用画像は未制作。
- UIの実装案であり、現行アプリの完成版でも、仕様確定版でもない。

## 収録
- `index.html` / `prototype/index.html`: インタラクティブな7画面のUIプロトタイプ。
- `tokens/`: v1.1のJSON/CSSトークン。
- `assets/`: 承認済みC系の暫定イラスト切り抜きとmanifest。
- `spec/SCREEN_SPECS.md`: 画面別仕様・データ境界・未決定事項。
- `spec/ACCEPTANCE_CRITERIA.md`: デザインの受け入れ基準。
- `spec/IMPLEMENTATION_HANDOFF.md`: Claude CodeとCodexへの作業分担。
- `spec/ILLUSTRATION_GUIDELINES.md`: イラスト運用ルール。

## 実装前のブロッカー
1. 現行エンジンの入力/出力型とサンプル数値の厳密な紐付け。
2. 必要な質問項目の網羅と既存ルーティングの統合。
3. 計算時系列から正確に描画するチャート。
4. 既存UI/CSSとの結合、アクセシビリティ確認。
5. 390pxを含む複数幅・Playwright視覚検証。
6. 本番用イラストの採用可否・横長素材の作成。
7. 履歴の保存・個人情報の扱いの設計。
