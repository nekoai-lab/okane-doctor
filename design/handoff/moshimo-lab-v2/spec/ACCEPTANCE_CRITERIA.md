# デザイン受け入れ基準

- [ ] 390px/360px/768pxで横スクロール・テキスト切れがない。
- [ ] 本文14〜16pxを基準とし、重要なラベルや脚注も判読できる。
- [ ] 主要操作領域は原則44px以上。キーボードで操作可能。
- [ ] フォーカス・選択・エラー・無効・読み込み・空状態を区別できる。
- [ ] カラーだけに意味を依存しない。文字ラベルと併用する。
- [ ] テキストと背景はWCAG AAに準拠するよう実測確認する。
- [ ] 承認済みCの人物・背景イメージのタッチを保持する。
- [ ] 架空の金額、仮の内訳、公的制度の断定的説明を混入させない。
- [ ] 7つのシナリオの数値、判定、未算定がエンジン出力と一致する。
- [ ] 死亡保障と病気・休職の費用を単純比較・合計しない。
- [ ] 年齢スライダー変更時に基準日・25年分の値と整合する。
- [ ] 申込誘導、商品名、恐怖を煽るコピーがない。
- [ ] Playwrightスクリーンショットでデザイン差分をレビューする。
- [ ] PC、モバイル、支援技術環境を検証する。
- [ ] 既存ロジック・機能の回帰テストが通る。
