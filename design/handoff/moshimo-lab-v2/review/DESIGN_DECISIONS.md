# DESIGN_DECISIONS — もしもラボ Design Handoff v2.0（2026-10-17）

## 確定事項（今回変えていない）

- UI：Modern Fintech A。白・ネイビー・ブルー。色の値（`tokens/tokens.css`）・角丸・余白・カードの構成は原本のまま
- イラスト：承認済み C。家族4人の川辺の画像をホームに1点。画像・切り抜き・人物は変えていない
- 中立性：商品名・申込誘導なし。「保険商品を販売したり、申込みへ誘導したりしません」の注記は原本のまま
- 数値：計算エンジンの出力（`sample-data.json`）だけ。試作の入力とは連動しないことを各画面に明記
- 死亡保障と医療・休職は別カードで、合計・順位づけしない

## 要ユーザー判断

推奨どおりに試作へ反映済みのものは「反映済み」と書いた。違えば戻す。

## アプリ全体に広げるときの論点（Naomi さんの「アプリ全体に反映したい」を受けて）

現行の CLAUDE.md「デザイン」節は **Airbnb の面・色＋デジタル庁 DS**。Fintech A を全体に入れると、次を書き換えることになる。

| 現行の規則 | Fintech A での扱い（案） |
|---|---|
| CTA はブランドの赤（Rausch `#ff385c`） | ブルー `#006EE6` に替える。判定色と CTA 色が別系統なのは同じ |
| 金額は Shippori Mincho の大サイズ | Noto Sans JP の太字・ブルーに替える（試作どおり） |
| 不足は Warning オレンジ `#c74700` | 試作は `#925300`（茶寄りのオレンジ）。どちらも「赤にしない」は同じ。値をどちらにするか決める |
| 減らせるは Success グリーン | 試作も `#16734A` のグリーン。整合 |
| 判定は「アイコン＋ラベル＋色」 | **残す**（D-3） |
| フォーカスリング Yellow-300＋Black | **残す**（D-3） |
| グラフはモックの SVG を移植、汎用ライブラリ禁止 | 残す。帯の色 `#F7D7BF`・線 `#D76A2B` は Fintech A のトークンにある |
| UI は `src/design/tokens.css` のセマンティックトークンだけを参照 | 残す。Fintech A の値をセマンティックトークンとして入れ直す（`--ml-*` のプリミティブを UI から直接使わない） |
