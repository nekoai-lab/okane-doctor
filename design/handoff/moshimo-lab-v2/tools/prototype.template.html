病気・休職の判定（貯蓄と比べて）

貯蓄の比較帯の下端が、負担の幅の上端を上回っている状態。入力条件では貯蓄で受け止められる見込みです。

負担の幅と貯蓄の比較帯が重なっている状態。貯蓄・家計・制度の条件をもう少し確かめたいケースです。

金額を出せる前提がそろっていないケース。ゼロ円を意味しません。

死亡保障の判定（いまの保障と比べて）

いまの保障が、必要額の幅の下端を下回っている状態。不足はエラーではなく、確認の目安です。

よくある質問

この金額は保険で用意すべき金額？

いいえ。生活や制度、貯蓄等を踏まえた参考値です。保険商品の購入を指示するものではありません。

病気と死亡の金額を比較できる？

算定対象や資産控除の扱いが異なるため、単純な比較や足し算はしません。

数字はAIが作っていますか？

いいえ。数値は計算エンジン由来です。文章も計算結果を変えないように扱います。

中立的な試算・試作デザインです。商品販売・申込誘導はありません。画面に表示した金額は README の特定サンプル（計算済み・）に対応しており、条件入力の操作では再計算されません。
