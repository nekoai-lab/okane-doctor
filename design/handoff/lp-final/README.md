## 実装上の重要な線引き

このリファレンス2枚は **画像生成によるデザイン画**であり、そのまま動作するHTMLや正確な画面コピーの証拠ではありません。
画像の「2,000〜3,000万円」「1,200万円」などは**仮の数字**。ソースコードに固定してはいけません。数値・判定は既存 `topExample` / 計算エンジンからデータバインドし、モデルケースの条件・計算時点・出典を表示。正確な値に応じて結果部分のレイアウトを調整すること。
画像上の「ログイン」「無料」「すぐに結果がわかる」などの文言・動線も仕様としては未承認。機能やデータ取り扱いを確かめてから入れる。LPの本文では家計全般の助言ができると誇張しない。

`prior-implementation/` は以前作成したHTMLモックの再利用用であり、**視覚正本ではない**。矛盾するときは参照画像と承認済みコンセプトに従う。必要であれば構造は作り直してよい。

## 守るコンセプト

「お金の町医者」＝暮らしの状況を聞く→計算に基づく診断→結果を理解→『もしもラボ』で気になる条件を確かめる。
診断は保険の販売ではなく、今の暮らしと備えを知る入口。保険商品名・保険会社名・申込誘導・不安をあおる文言は禁止。AIは金額を生成しない。
自由な自然言語チャットについては、現行機能確認なしに約束しない。
