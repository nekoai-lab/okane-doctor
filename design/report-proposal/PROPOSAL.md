# お金の町医者｜診断レポートのデザイン提案

作成日：2026-10-18。対象：main `7e5b555` の結果画面。計算エンジンを変更しない、表示と読む順の提案です。

## 1. 提案の中心

**「結論 → 金額の根拠 → 見直す時期 → 他のリスク → 前提・出典」の5節で、お客様が順に確かめられるレポートにする。**

現在は、結論・必要額・収入の内訳・生活費の選択・時系列が長い縦列に入り、同じような棒が異なる意味で繰り返されています。情報を削るより、各節の問いと役割を分けます。

- 冒頭だけで「今回の結論」「次の一歩」「結論を左右する前提」が分かる。
- 本文は番号と見出しで進み、各節の冒頭に「ここで分かること」を置く。
- 金額は、**不足分／必要額／現在の保障／まんなかの目安**を必ず名札付きで表示する。
- 図は、比較・構成・時間という目的ごとに型を変える。単なる長さの装飾は使わない。
- 説明文は数値の近くに置く。「AIによるよみとき」の独立した長い節は、結論の再掲を避けて各節へ統合する。

## 2. 読む順と節の構成

### 最初の読み方

「この順にお読みください」という目次を置きます。スマホは短いリンクの折り返し、PCは左の追従目次です。順番に読んでも、目的の節へ飛んでも理解できるよう、節内に対象者と金額の意味を再掲します。

| 順番 | 見出し | ここで分かること | 読後に分かっていてほしいこと |
|---|---|---|---|
| 01 | まず、今回の結論 | どの保障を確認するか | あなたにも配偶者にも、不足の可能性がある。まず保険と共済の死亡保障額を確認する |
| 02 | 金額の根拠を確かめる | 必要額と、いまの保障の関係 | 保障が幅の左端にも届いていない。内訳の目安と必要額の幅は別物 |
| 03 | いつ、見直すか | 必要額の変化と確認する時期 | 必要額は減る見込みだが、子の加算・大学の学費など、確認すべき時期がある |
| 04 | 他のリスクも見渡す | 病気・休職などへの備え | 死亡以外の判定と未算定項目。貯蓄は各行で共通している |
| 05 | 前提を確認して、次へ | 結果を読むうえで確認したい点 | 保障額・働き方・暮らし方を確かめてから、必要なら入力を見直す |

### 最初の2画面に入れるもの

390×844pxの上から2画面を設計の基準にします。上部のタイトルや目次は短くし、01節に次をまとめます。

1. 世帯属性と「概算・要精査」の注記。
2. 本人と配偶者の結論・不足分・いまの保障。
3. 「次の一歩：保険と共済の死亡保障額を書き出す」。
4. 前提となる配偶者の就労収入、働かない場合の影響。

01節の後、詳細に進まなくても最初の行動が決まります。全リスクの詳細表を冒頭に挟まず、目次から04へ直接進めます。見直し年の理由は03にまとめます。

## 3. 情報ごとの図表の型

| 情報・何を伝えるか | 図表の型 | なぜこの型か | 描画・読み方の注意 |
|---|---|---|---|
| 世帯の結論：誰の保障を確認するか | 一文の結論＋対象者別サマリーカード | 最初の数秒で対象・判定・差額が分かる | 本人と配偶者を分ける。2人分を足さない。金額の上に「必要額に足りない分」 |
| 次の一歩：具体的にすること | 青い左罫線付きの行動ボックス | 図にするより、動詞で短く伝える方がよい | 商品や窓口へのリンクにしない。見本のリンクは前提確認へ |
| 結論を左右する前提：就労収入の仮置き | 前提名＋大きな金額＋外れた場合の一文 | 収入の比率より、前提の有無が判定に効くことを伝えたい | 約1,000万円は年額ではなく算定期間の合計。年100万円の前提とは区別 |
| 必要額と保障の関係 | **共通の目盛りを持つレンジ比較図**（青い区間＋紺の縦印） | 「届いていない／幅の中／上回る」という位置関係を直接見せられる | 同一図では本人・配偶者を同じ尺度にする。0円の印も見えるようにする |
| なぜその必要額になるか | **支出と収入・資産を分けた明細表** | どのお金を考慮したかをラベルと金額で正確に確認できる | 算術が再現できないウォーターフォールや円グラフにしない。就労収入には「当社基準」 |
| 必要額が時期によって変わる | **2時点の数値カード**＋**出来事の年表** | 確認できる値だけで変化と見直す理由を分けて示せる | 2026年の約8,400万円と2036年の約3,800万円。中間年の金額は創作しない |
| 将来の年ごとの必要額（本実装で既存系列を使える場合） | 数値系列に基づく折れ線／必要額の面＋保障の線 | どの年まで現在の保障を上回るかを連続的に読める | 見本では省略。既存エンジンの系列をそのまま使い、直線補間から新たな算定値を作らない |
| 病気・休職を含む全体像 | **リスク別の比較表**。スマホでは同じ行をカード化 | リスク名・必要額・受け皿・判定が同じ順で見つかる | 棒の長さのランキングにしない。未算定も行として出す |
| 貯蓄の重複利用 | 共通注記＋大きな貯蓄額 | 各行の貯蓄を足せないことが分かる | 約50万円は各ケース単独の受け皿。世帯金融資産約100万円と統合しない |
| 次に確認する前提 | チェックリスト | レポートを読んだ後に手元の契約・回答を確認しやすい | 見本は確認項目の表示のみ。完了状態の保存を装わない |
| 出典・制度・詳しい前提 | 件数の要約＋意味ごとの折りたたみ | 本文の読み進めやすさと根拠へのアクセスを両立できる | 結論を左右する前提は折りたたまない。件数だけで根拠を説明した扱いにしない |

### 明細をウォーターフォールにしない理由

現行テキストには以下が併存します。

- 総額：約1億1,100万円。
- 遺族年金：約1,700万円、就労収入：約1,000万円、貯蓄・資産：約100万円。
- 必要額の幅：約6,200万〜1億600万円。
- まんなかの目安だけの幅：約6,700万〜1億円。
- 現時点のまんなかの目安：約8,400万円。
- 冒頭の「見込んだ収入・資産の合計」：約2,700万円。

丸め、範囲、算定対象の違いを、この文字情報だけから一つの等式に再構成できません。そこで今回の見本では**各明細を独立した既存値として示し、差額・割合・合計を新たに計算しません**。「約2,700万円」の比例棒も省きます。数値を黙って訂正することはしません。

本実装でウォーターフォールを採用するには、表示レイヤーが使用する各値の意味・同じ算定条件での整合性を既存出力から確認する必要があります。エンジンの変更や、UI側の補正によるつじつま合わせはこの提案の範囲外です。

### 比較図の約束

- ブルーの区間＝必要額の幅。紺の縦印＝いまの保障。
- 幅は回答区分による算定範囲。確率・信頼区間・推奨保険商品の保障額ではありません。
- 不足世帯の図の目盛りは0円と約1億600万円の両端。390pxで中間目盛りを無理に詰めない。
- 各金額はHTMLでも読める。SVGにはtitleと説明を付ける。
- 区間の座標は、共通尺度上の既存金額に比例させる。見栄えのために最小幅を誇張しない。
- 図を別世帯に切り替えると尺度も変わり得るため、別画面の棒の長さを比較しない。

### 1280px：目次を見ながら比較できる

全体の最大幅1160px（左右内側24pxを含む）。左目次196px、列間36px、本文は残り約880pxです。スマホと同じDOM順を保ちます。

```text

│ 01 結論      │  │ タイトル／世帯属性                │

│ 05 前提・出典│  │                                 │
```

| 要素 | 390px | 1280px |

| 目次 | 冒頭、短いアンカーリンクが折り返す | 左列に追従。本文に重ならない |
| 本人・配偶者 | 縦に2カード | 横に2カード。順番は同じ |
| 本文 | 14px・行高1.75 | 同じ。横幅は本文列で制限 |
| 大きな金額 | 23〜26pxを中心に使う | 26〜28pxを中心に使う |
| 比較図 | 端の目盛りを優先。注記はSVGの外 | 同じ尺度と凡例。図の文字を縮小しない |
| 明細 | 項目左・金額右。項目の補足は下段 | 同じ位置関係で余白を広く |
| リスク一覧 | 表の各行を縦カードにする。列名を各値に再掲 | 列見出し付き4列の表 |
| 前提と出典 | 詳細は折りたたみ | 同じ。余った幅を文章で埋めない |

## 5. 色・文字・判定のルール

最新の依頼を優先し、参考の旧トークンにある茶色・オレンジの判定／図色は採用しません。

| 用途 | 色・表示 |
|---|---|
| 基本の面 | 白 `#FFFFFF`、補助背景 `#F5F9FD`／`#EFF7FF` |
| 本文・大きな金額 | ネイビー `#102A50` |
| CTA・リンク | ブルー `#006EE6` |
| 必要額の区間 | ブルーの枠 `#006EE6`＋塗り `#82B8FA` |
| 不足の判定 | 文字 `#9D3656`／背景 `#FFF0F4` |
| 減らせる可能性のみ | 文字 `#16734A`／背景 `#E8F6EC` |
| 中立・未算定・貯蓄で足りるめやす | ネイビー／薄いグレーブルー。緑にしない |

| 判定ラベル | 記号 | 色の扱い |
|---|---|---|
| 不足の可能性 | ! | ピンク |
| 備え不足の可能性 | ! | ピンク |
| 足りない場合あり | ↔ | ピンク |
| 減らせる可能性 | ↓ | 緑 |
| 組み替えの余地 | ⇄ | 中立色。本人・配偶者はそれぞれの判定色 |
| 貯蓄で足りるめやす | ✓ | 中立色 |
| 幅の中・要確認 | ↔ | 中立色 |
| 未算定 | … | 中立色 |

- 色と記号だけに依存せず、すべて文字ラベルを添えます。判定の軸名「過不足の判定」も残します。
- 本文14px以上。凡例・補足・目盛り・バッジも12px以上。金額の桁を減らして収めません。
- 金額は下限・上限をそれぞれ`white-space: nowrap`の要素にします。範囲全体は折り返し可能にし、`〜`を次のまとまりに含めます。
- フォントはsystem-ui。数字はtabular-numsで揃えます。
- 読み上げではラベルを読み、装飾の記号は重複して読まないようにします。
- フォーカスは見本ではブルーの輪郭。本実装は既存のアクセシビリティ仕様と統合して、背景ごとの視認性を確保します。

## 7. 3世帯への適用

| 世帯 | 01の結論と数値 | 02・03の出し分け |
|---|---|---|
| 不足 | 本人：約6,200万〜1億600万円不足、配偶者：約400〜8,600万円不足。ともに保障0円 | 必要額の幅と保障を比較。就労の仮置きを明示。2036年ごろの見直し |
| 組み替え | 本人：減らせる可能性・上回る分約800〜1,800万円。配偶者：不足の可能性・不足約200万円 | 本人の必要額約200〜1,200万円と保障約2,000万円を比較。配偶者の不足と相殺しない。就労収入約4,800万円の前提を先に。次の見直し2042年ごろ |
| 単身 | 減らせる可能性・上回る分約800万円。必要額約200万円、いまの保障約1,000万円 | 対象者1カード。扶養する家族がいないことを前提として明示。存在しない配偶者や将来の金額を補わない |

組み替え世帯では「前提どおりなら上回る分」を現金残高に見せません。就労収入を含む将来の見込みであることを添えます。「上回る分で配偶者の保障を賄える」「保険料が増えない」などの新しい約束は加えません。

単身には時系列が提供されていないため、03は「契約を見直す前に」の確認項目に切り替えます。保障額・期間・更新の時期を確認する現行の案内を使い、新しい見直し年は作りません。目次も節名と一致させます。

## 9. 実装するときの注意

### データと計算

- エンジンの出力値・判定をそのまま表示します。UIで必要額や不足額を再計算しません。
- 不足分・必要額・上回る分は別フィールドとして扱い、ラベルと値を一緒に切り替えます。
- 貯蓄で受ける病気・休職と死亡保障は、合計や一つの安全度に変換しません。
- 同じ額でも、時点・対象者・回答区分の目安か範囲かを保ちます。
- 暮らし方を変える本実装では、既存の再計算処理を使います。新旧結果が同時に見えないようにし、変更後の前提・結論・表・図を一括更新します。
- 再計算中・未算定・値が得られない状態を区別し、不明な値を0円にしません。

### 詳細情報と導線

- 見本は全文の複製ではありません。既存の「毎月の家計」「金額の内訳」「教育費の進路別比較」は本実装で02／03の詳細へ配置します。
- 公的出典6件・当社基準18件の全文は提供テキストには展開されていません。見本で架空の明細やリンクを作らず、省略を明示しました。本実装は既存データを移します。
- 2028年改正は、対象外なら05の詳細へ。組み替え世帯のように対象の場合は、現行が改正前の制度での試算である点を結論付近にも明示します。
- 世帯の平均保障額は、必要保障額の目標と混同しやすいため、参考情報として05の詳細へ置きます。
- 入力をやり直す導線は既存の入力画面へ接続します。見本では存在しない入力画面や準備中機能へのダミーリンクを作っていません。
- AIの説明文を使う場合も、数値・判定の出力元は既存エンジンであることを05に残します。見本の文章はデザイン説明のための固定文です。

### レスポンシブ・アクセシビリティ

- SVGのviewBox全体を縮めて12pxを割らないようにします。小さい幅は文字サイズを維持し、目盛りを減らすか図を再配置します。
- 表はcaptionと列見出しを持ちます。モバイルで行をカード化する際は、スクリーンリーダーの表認識を維持できるか検証します。
- アンカー移動、detailsのキーボード操作、フォーカス可視性を確認します。追従目次で本文を隠しません。
- 390pxでの金額の改行は範囲の区切りのみ。文字拡大時も、金額が切れるoverflow:hiddenを使いません。
- 844pxごとの視覚要素は、比較図・目安の数字・表・貯蓄額・出典件数など意味のある情報で確保します。飾りのバーを追加して達成扱いにはしません。
